# naoblock builder 3D

ナノブロックの立体（ミニナノ風）を、1個ずつ案内する組立ガイド・色と形を合わせるゲーム・A4の組立図PDFで遊べるアプリ。

https://builder-3d.naoblock.jp/

- `index.html`：キャラ選び・組立ガイド（買い物リスト・組立図PDF）
- `game.html`：ゲーム（♥3・タイム・コンボ・シェア画像・組立図PDF）
- `print3d.js` / `print.css`：組立図（[naoblock-builder](https://github.com/naonao1971/naoblock-builder) の組立図と同じ作り）
- `kit.js`：2D・3D 共通の部品（音・紙吹雪・コンボ・♥・PDF）の読み込み。中身は [naoblock-kit](https://github.com/naonao1971/naoblock-kit)
- `plan*.js`：作品のデータ（段・色・形・置くマス）

nanoblock（ナノブロック）は株式会社カワダの登録商標です。本アプリは非公式のファン作品です。
